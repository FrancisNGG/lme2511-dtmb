# 分析脚本

本目录保存开发过程中使用的 Python 分析脚本，用于记录分析方法、保证可复现。

## 分类

| 前缀 | 用途 |
|---|---|
| `dis_*.py` | 反汇编参考二进制指定地址的函数 |
| `find_*.py` | 查找交叉引用 / 调用关系 / 寄存器写 |
| `scan_*.py` | 扫描解调器 / 调谐器寄存器写入序列 |
| `parse_*.py` | 解析 usbmon 抓包日志 |
| `analyze_*.py` / `cmp_*.py` / `calc_*.py` | 固件 / 载波 / 寄存器分析 |
| `dbg_*.py` / `read_*.py` / `verify_*.py` / `xrefs.py` / `disasm.py` | 辅助分析 |

## 注意

- 脚本内硬编码了当时的临时路径，归档后路径已变，**重跑需先改路径**。
- 这些脚本是开发过程的记录，**非驱动编译 / 运行所需**。
